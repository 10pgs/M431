À propos du projet

Game Store, une boutique de jeux simple et complète

Game Store est une application web inspirée des plateformes de vente de jeux vidéo. Le but est de proposer un catalogue clair, des fiches de jeux détaillées, un espace utilisateur et une page d'avis pour partager son retour avec les autres joueurs.

Catalogue

Les jeux sont présentés avec leur image, leur prix, leur description et un lien vers la page officielle.

Compte utilisateur

Un joueur peut créer un compte, se connecter, consulter son profil et retrouver ses informations.

Avis

Les utilisateurs connectés peuvent publier une note et un commentaire sur les jeux du catalogue.

Objectif

Le projet met en pratique une structure web complète avec HTML, CSS, JavaScript, PHP, MySQL et Docker. L'idée est d'avoir un site cohérent, utilisable et facile à faire évoluer.
